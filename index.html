Quét PDF

Chụp ảnh, tự cắt khớp khổ A4, gửi nhiều PDF riêng một lúc.

Tài liệu mới

Chưa có trang nào. Bấm “Chụp ảnh”, chĩa vào 1 trang, thấy khung xanh thì bấm chụp. Sổ mở 2 trang thì để trang cần chụp ở giữa màn hình.

File PDF đã tạo

Chưa có file PDF nào.

Tích chọn nhiều file rồi bấm “Gửi”, chọn Zalo. Mỗi file gửi đi là một PDF riêng, không bị nén zip. File được lưu trên máy này, không tải lên đâu cả.
